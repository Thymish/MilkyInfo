# Support

Une question, un problème, une idée ? Écrivez‑nous à
[thymishstudio@gmail.com](mailto:thymishstudio@gmail.com). Nous répondons en général sous 48 heures.

Pour nous aider à comprendre, précisez si possible votre modèle d'iPhone, la version d'iOS et la
version de Milky (visible dans **Réglages → Informations**).

## Questions fréquentes

### Mes biberons sont‑ils sauvegardés ?

Avec l'offre gratuite, les biberons sont enregistrés **uniquement sur votre téléphone** : si vous
supprimez l'application, ils sont perdus. Avec l'offre premium, ils sont synchronisés en ligne et
vous les retrouvez sur tous vos appareils.

### Comment partager le suivi avec un proche ?

Le partage fait partie de l'offre premium. Dans les réglages, choisissez **Inviter un nouveau
membre** : Milky génère un code à six chiffres à transmettre à votre proche. Celui‑ci installe
Milky, choisit **Rejoindre un espace** et saisit le code.

### Mon code d'invitation ne fonctionne pas

Un code n'est valable que 7 jours et une seule fois. Si Milky indique qu'il a
expiré ou qu'il est invalide, demandez un nouveau code à la personne qui vous a invité.

### Comment retirer un invité ?

Le titulaire de l'espace peut révoquer un invité depuis la carte **Invités** des réglages.
L'invité perd aussitôt l'accès aux biberons de l'espace.

### J'ai changé de téléphone : comment retrouver mon abonnement ?

Connectez‑vous avec le même compte Apple, puis touchez **Restaurer mes achats** sur l'écran de
l'offre premium.

### Comment résilier mon abonnement ?

Les abonnements sont gérés par Apple. Dans Milky : **Réglages → Abonnement → Annuler mon
abonnement**, puis **Gérer mon abonnement avec Apple**. Vous pouvez aussi passer par l'app Réglages de l'iPhone : votre nom → Abonnements.
La résiliation prend effet à la fin de la période en cours.

### Comment obtenir un remboursement ?

Les remboursements sont décidés par Apple. Faites votre demande sur
[reportaproblem.apple.com](https://reportaproblem.apple.com).

### Que se passe‑t‑il si je repasse à l'offre gratuite ?

Vos biberons restent sur votre téléphone, mais la synchronisation s'arrête et les proches invités
dans votre espace perdent l'accès.

### Comment supprimer mon compte ?

Dans **Réglages → Informations → Supprimer mon compte**. La suppression est définitive. Le détail
de ce qui est effacé figure dans la
[politique de confidentialité](confidentialite).
